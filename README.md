# 🦄 Il Regno Magico di Camilla

Un videogioco fatto con amore dal babbo per Camilla.
Funziona nel browser di cellulare, tablet e computer, anche senza internet dopo la prima apertura.

## Cosa c'è dentro

Stellina, l'unicorna di Camilla, la accompagna in 8 giochi. Una voce parla in italiano, così non serve saper leggere,
e ogni tanto ricorda a Camilla che il suo babbo le vuole bene.

| | Gioco | Cosa si fa |
|---|---|---|
| 🦄 | **Vola!** | Guida Stellina col dito e raccogli 30 stelline. Le nuvolette grigie fanno perdere un paio di stelle, ma non si perde mai |
| 🫧 | **Bolle** | Scoppia le bolle del colore che dice la voce (rosa, azzurre, verdi…). Ogni tanto arriva una bolla d'oro |
| 🃏 | **Memory** | Trova le coppie di animali. Ci sono 4 livelli che si sbloccano uno dopo l'altro |
| 👑 | **Stellina** | Scegli il colore, la criniera, il corno, gli accessori e lo sfondo. Poi fai una foto! |
| 🎨 | **Colora** | Pennello, arcobaleno, brillantini, timbrini e secchiello per i disegni da colorare (cuore, farfalla, fiore…) |
| 🐾 | **Cucciolo** | Dai la pappa, fai il bagnetto strofinando, gioca con la palla, metti a nanna e fai le coccole |
| 🎹 | **Musica** | Pianoforte con gli animali. Le canzoncine guidate sono *Brilla brilla la stellina*, *Fra Martino* e *Nella vecchia fattoria* |
| 📒 | **Album** | 36 figurine da collezionare (6 sono rarissime e brillano) e tutte le foto e i disegni |

Ogni gioco finito regala una figurina dentro un pacchetto da aprire. Ogni giorno nella mappa c'è anche un 🎁 regalo a sorpresa.

## Pubblicarlo su GitHub Pages (gratis)

1. Crea un repository su GitHub, per esempio `regno-magico`.
2. Carica il contenuto di questa cartella, da riga di comando:
   ```bash
   git remote add origin https://github.com/TUO-UTENTE/regno-magico.git
   git push -u origin main
   ```
   oppure trascina i file in **Add file → Upload files**.
3. Vai su **Settings → Pages**, imposta *Source* su **Deploy from a branch**, scegli `main` e `/ (root)`, poi premi **Save**.
4. Dopo un minuto il gioco è online su `https://TUO-UTENTE.github.io/regno-magico/`.

## Sul telefono di Camilla

Apri il link e poi:
- **Android / Chrome**: menu ⋮ → **Aggiungi a schermata Home**
- **iPhone / Safari**: tasto Condividi → **Aggiungi alla schermata Home**

Così il gioco si apre a schermo intero come una vera app, con l'icona di Stellina.
Alza il volume: la voce e la musica sono una parte importante del gioco.

## Per il babbo

- L'**⚙️ area genitori** (in alto a destra nella mappa) è protetta da una moltiplicazione. Da lì si accendono o si spengono la voce e la musica, oppure si azzera tutto.
- I progressi (figurine, foto, cucciolo) restano salvati nel telefono, nel browser che si usa.
- Non ci sono pubblicità, account, dati inviati o librerie esterne. Dall'esterno si scarica solo il font Fredoka da Google Fonts.
